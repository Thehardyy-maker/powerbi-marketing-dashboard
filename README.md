# Power BI Marketing Campaign Dashboard

## Overview
This project analyzes marketing campaign performance across multiple channels and countries using Power BI.

The dashboard provides insights into:
- Revenue trends
- ROI performance
- Campaign effectiveness
- Geographic performance
- Executive recommendations

---

## Dashboard Pages

### 1. Executive Summary
- KPI cards
- Revenue trends
- Revenue share by channel
- ROI analysis
- Interactive slicers

### 2. Campaign Performance
- Campaign-level revenue analysis
- ROI heatmaps
- Top performing campaigns
- Performance comparison visuals

### 3. Geographic Analysis
- Country-wise revenue performance
- Interactive map visualization
- Regional marketing insights

### 4. Executive Insights
- Key business takeaways
- Recommendations
- Strategic observations

---

## Tools Used
- Power BI
- DAX
- Data Modeling
- Interactive Visualizations
